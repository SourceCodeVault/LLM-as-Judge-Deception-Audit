# Erratum: LLM-as-Judge Deception Audit (https://doi.org/10.5281/...PENDING...)

**Original paper:** LLM-as-Judge Deception Audit: Bounded Miscalibration Under Adversarial Perturbation  
**Erratum date:** 3 August 2026  
**Commit reference:** `a601190c`  

---

## 1. Summary

A normalization bug in the supplementary verification script `tools/scan_policy_gaps.py` caused it to undercount auditor breaks in the canary perturbation run (n=1,200). The primary analysis instrument (`tools/build_dashboard.py`) is unaffected. All pre-registered hypotheses (H1, H2) and all primary statistical claims remain unchanged.

## 2. What Changed

### 2.1 The Bug
`scan_policy_gaps.py` compared raw L2 judge action strings (`"APPROVED"`, `"BLOCKED"`, `"HESITATE"`) directly against normalized L3 auditor strings (`"APPROVE"`, `"BLOCK"`) using exact-match equality. Since no raw string equals its normalized form, the comparison never matched, and the script reported zero auditor breaks. The primary instrument (`build_dashboard.py`) correctly normalizes these strings before comparison.

### 2.2 The Fix
A `normalize_l2_action()` function was added to `scan_policy_gaps.py`, applied at the comparison point. 

### 2.3 The Corrected Finding
After the fix, `scan_policy_gaps.py` correctly reports 3 auditor breaks, identical to the 3 breaks found by `build_dashboard.py`. The 3 auditor break case IDs are:
- `6719a4ad27f0` — CLEAN bucket, L2=APPROVED(90), L3→BLOCK, severity HIGH
- `7d94cadba741` — CLEAN bucket, L2=APPROVED(90), L3→BLOCK, severity HIGH
- `a32fbd13c2e3` — ROGUE bucket, L2=HESITATE(60), L3→APPROVE, severity LOW

## 3. Impact on Paper Claims

All primary claims (H1, H2, quadrant counts, and 8-cell exploratory tables) derive from `build_dashboard.py` and are **unchanged**.

**Revised Claim (§5.8):**
*   **Original:** "The independent policy-gap scan over the 1,200 perturbed files records zero auditor breaks, zero cross-variant gaps, and zero schema crashes."
*   **Revised:** "The independent policy-gap scan over the 1,200 perturbed files records 3 auditor breaks (matching the primary dashboard output), zero cross-variant gaps, and zero schema crashes." *(Note: cross-variant gaps are structurally vacuous on a single-variant run).*

## 4. Methodological Note

This correction demonstrates the value of shipping analysis code alongside preprints. The bug was discovered by reviewer Giorgi Tsereteli, who independently ran the verification script and noticed the discrepancy. The open-source methodology functioned exactly as designed.
